## 제출 결론

현재 모델은 S3에서 11번 접근 마지막 간선이 차단되면 `C_CENTER`에서 12번 방향으로, 계단 A가 차단되면 `P_SOUTH`에서 계단 B 가정 방향으로 경로가 바뀌는 것을 확인한다. 계단 A+B를 모두 제외하면 S3에서 도달 가능한 경로가 없다. S1/S2는 해당 차단 간선을 기본 경로에 사용하지 않으므로 같은 조건에서 결과가 변하지 않는다.

이 결과는 **단순화 그래프의 연결성과 가정 비용 비교**이며, 실제 서울역의 위험도·혼잡·안전성·공식 피난 동선을 확인한 결과가 아니다.

## 모델이 확인한 사실

- 결과 수치와 노드/간선 순서는 현재 백엔드 계산으로 재현됐다.
- S3 화재 A/B는 각각 기본 경로에 포함된 `E11_OUT`/`STAIR_A`를 제거한다.
- 안내 후보 분기점과 차단 간선은 별도 객체이며 위치가 같다고 간주하지 않았다.
- 도달 불가 결과에는 출구·거리·시간을 부여하지 않았다.
- 모델은 입력된 고정 차단만 처리하며 재난 확산이나 인파 흐름을 예측하지 않는다.

## 추가 현장 검증이 필요한 사항

- 프로토타입 내부 연결, 계단 B, 간선 길이와 실제 층별 위치
- 일반 출구 후보가 재난별로 사용 가능한 공식 피난 출구인지 여부
- 재난 감지·폐쇄 정보가 각 결정 지점에 도달하는 시간과 전달 수단
- 안내 후보의 시야, 회차 공간, 접근성, 전원·통신 및 설치 허가
- 실제 보행자 반응, 다국어·장애인 접근성, 공식 안내 체계와의 충돌 여부
