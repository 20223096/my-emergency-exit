검증일: 2026-10-23 (Asia/Seoul)

이 문서는 `virtual-station-v1` 가상 지도와 실험용 가정값을 이용한 결과입니다. 실제 서울역 구조나 실제 재난 시 안전성을 나타내지 않습니다.

실행 명령:


검증 범위는 지도 모델 검증, 기본 경로, 통로 차단, 출구 폐쇄, 혼잡, 복합 조건, 경로 없음, 결정적 동률 처리, 이동속도, 반응시간, 일방통행, 비교 API, 오류 응답, 프론트엔드 참조 무결성 및 로컬 CORS 정책입니다.

## A12/A17 평행 간선 검토

- A12는 `T1 → E3` 21m 양방향이므로 `T1 → E3`, `E3 → T1`을 모두 제공합니다.
- A17은 `E3 → T1` 18m 일방향이므로 `E3 → T1` 방향에서 A12와 겹칩니다.
- 현재 엔진은 NetworkX가 아닌 자체 인접 리스트를 사용하며, 서로 다른 간선 ID를 별도 항목으로 보존하고 개별 차단합니다.
- A12만 차단한 S3 출발 회귀 테스트에서 A17은 역방향 전용이라 E3 도착 우회로로 사용되지 않았고, 경로는 E2로 변경됐습니다.
- 샘플 지도 품질 검사는 `(A12, A17)`과 겹치는 방향 `E3 → T1`을 정확히 경고합니다.
- 두 ID가 동일 물리 통로인지 별도 통로인지 근거가 없어 삭제하거나 합치지 않았습니다. 실제 지도 자료 수신 후 확인이 필요합니다.
- 향후 NetworkX로 전환한다면 일반 `DiGraph`는 노드 쌍당 단일 간선 속성만 가지므로 부적합하며, 간선 키로 ID를 보존하는 `MultiDiGraph`를 사용해야 합니다.

## 공통 입력 조건

- 지도: `virtual-station-v1`
- 출발점: `S1`
- 보행속도: `1.2 m/s`
- 반응시간: `5초` (출발 전 한 번만 적용)
- 표의 모의 이동시간은 반응시간을 포함한 `total_time_s`입니다.

## Swagger API 예외·경계 조건 확인

실행 중인 FastAPI의 Swagger와 동일한 엔드포인트에 실제 HTTP 요청을 보내 다음 결과를 확인했고, 동일 조건을 자동화 테스트에도 추가했습니다.

| 조건 | HTTP/결과 | 확인 내용 |
|---|---|---|
| `walking_speed_mps=0` | 422 | Pydantic의 `greater_than` 검증으로 거부 |
| E1·E2·E3 전체 폐쇄 | 200, `reachable=false` | 경로 배열은 비어 있고 출구·거리·시간은 null |
| A04 혼잡 120초 | 200 | E1에서 E2로 변경, A18→A10→A13→A09 |
| A04 혼잡 120초의 비교 | 200 | 거리 +13m, 총시간 +10.833초 |
| 반응시간 0초/5초 비교 | 200 | 이동시간은 모두 50초, 총시간만 50초→55초로 증가 |

반응시간은 구간마다 반복되지 않고 최종 모의 이동시간에 정확히 한 번만 포함됐습니다.

## 프론트엔드 연동 검증

- 지도 응답의 모든 노드에는 숫자형 `x`, `y`와 `floor`가 있습니다.
- 모든 간선의 `source`, `target`은 실제 노드 ID를 참조합니다.
- 계산 결과의 모든 `path_nodes`, `path_edges`는 지도 응답에서 조회할 수 있습니다.
- 경로의 간선 수는 노드 수보다 정확히 하나 적어 순차 선분 렌더링이 가능합니다.
- 개발 CORS 출처는 `localhost`와 `127.0.0.1`의 포트 `3000`, `5173`만 허용합니다.

React에서는 `/api/maps/{map_id}`를 한 번 조회해 노드·간선을 ID 기반 사전으로 만들고, 경로 응답의 ID 배열 순서대로 강조 표시하면 됩니다. `x`, `y`는 상대 좌표이므로 SVG `viewBox` 또는 화면 크기에 맞게 스케일링해야 하며 실제 거리 환산에 사용하면 안 됩니다.

## 실험 가정과 한계

구간 비용은 `length_m / walking_speed_mps + congestion_delay_s`이며, 반응시간은 최종 시간에 한 번 더합니다. 계단 별도 속도, 통로 수용량, 사람 간 상호작용, 시간에 따른 혼잡 변화, 화재·연기 확산은 모델링하지 않습니다. 폐쇄 출구는 목적지와 중간 경유지 모두에서 제외됩니다. 상세 내용은 `ASSUMPTIONS.md`를 참고하세요.

모든 수치는 실험용 가상 지도와 가정값으로 계산한 비교 결과이며, 실제 대피시간이나 시스템 도입에 따른 시간 단축 효과를 의미하지 않습니다.
