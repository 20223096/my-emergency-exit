# AI 기능 후보 타당성 비교

작성 기준: 2026-10-28 / 기준 커밋 `f410b1f3d38f76de08413ef427e1a1365d2ea185`  
목표 시점: 2026-11-03 이전 예선 제출

> 이 문서는 기술 시험 **계획**이다. 실제 역사 영상·장소 사진·학습 데이터가 확보되지 않았고 AI 모델을 구현하거나 성능을 측정하지 않았다. 따라서 정확도, 실시간성, 지연시간 개선 또는 안전 효과를 입증하지 않는다.

## 1. 서비스 정보 부족과 AI 후보의 역할

현재 프로토타입은 사용자가 `S1/S2/S3`, 차단 간선, 고정 지연을 알고 입력한다는 전제에서 경로를 계산한다. 실제 이용자는 다음 정보를 모를 수 있다.

- 자신이 `C_CENTER`, `P_SOUTH`, `C_EAST`, `C_WEST` 중 어디에 있고 어느 방향을 보는지
- 특정 그래프 간선에 사람이 얼마나 모였고 어느 방향으로 움직이는지
- 관측이 불충분한 상황에서 시스템 판단을 믿어도 되는지

후보 A는 “구간 관측 상태”, 후보 B는 “사용자 위치·방향 후보”라는 서로 다른 정보 공백을 다룬다. AI를 붙이는 것 자체가 목적이 아니며, 둘 다 기존 경로 엔진의 안전한 입력이 되려면 별도 검증·보류 정책이 필요하다.

## 2. 비교 결론

| 기준 | A. 인파 흐름·정체 분석 | B. 위치·방향 확인 |
|---|---|---|
| 11월 3일 전 시험 가능성 | 낮음~중간. 권한 확보된 짧은 연출 영상으로 상태 분류 파이프라인만 가능 | 중간~높음. 통제된 후보 지점 사진으로 top-k 분류와 보류 시험 가능 |
| 데이터 확보 가능성 | 낮음. 실제 CCTV 사용 권한·촬영 고지·다양한 밀도 장면 필요 | 중간. 빈 공간 또는 동의한 참여자로 후보별 촬영 가능하나 현장 허가 필요 |
| 정답 라벨 신뢰도 | 낮음~중간. 가림, 원근, 구역 경계와 “정체” 정의에 영향 | 중간~높음. 촬영 위치·방향을 기록자가 직접 고정 가능 |
| 구현 난이도 | 높음. 검출·추적·ROI 보정·시간 집계 필요 | 중간. 이미지 임베딩/분류와 top-k·abstain 정책으로 제한 가능 |
| 오류 시 사용자 위험 | 높음. 정체 누락 또는 오탐이 경로 선택을 바꿀 수 있음 | 높음. 위치·방향 오인식은 잘못된 길 안내로 이어질 수 있음 |
| 경로 엔진 연결성 | 간접 연결. 상태를 검증된 정책이 지연/차단 입력으로 변환해야 함 | 개념상 직접적이나 현재 API는 START 노드만 허용해 어댑터/계약 변경 필요 |
| 실제 서비스 차별성 | 운영자가 보지 못한 구간 상태를 보조할 잠재력 | 사용자가 표지·지도 해석 없이 자신의 후보 위치를 확인할 잠재력 |
| 예선 권고 | “향후 시험 후보”; 실제 지연 초 추정 주장은 제외 | **우선 기술 시험 후보**; 통제 사진, top-k, 확인 요청까지만 제시 |

후보 B의 우선순위는 안전성이 더 높다는 뜻이 아니다. 짧은 기간에 정답을 통제하고 실패·보류율까지 측정하기 쉽다는 뜻이다. 실제 서비스 투입 전 두 후보 모두 현장 데이터와 안전 검토가 필요하다.

## 3. 후보 A — 인파 흐름·정체 분석

### 필요한 입력과 권한

- 카메라 ID, 촬영 시각, 프레임률, 해상도, 시야각과 설치 높이
- 그래프 간선에 대응하는 영상 ROI 및 진행 방향 기준선
- 짧은 시간창의 영상과 촬영 누락·역광·가림 메타데이터
- 정답 작성자가 확인할 원본과 익명화본, 라벨 이력

실제 CCTV나 공개 장소 촬영물을 받았다는 전제는 두지 않는다. 시험 전에 영상 소유자·시설 운영자의 제공/재사용 권한, 촬영 목적과 법적 근거, 정보주체 고지, 접근자, 보관기간, 파기 방식, 외부 서비스 전송·업무위탁 여부를 문서로 확인해야 한다. 확인되지 않으면 실제 영상 시험을 중단하고 합성 또는 동의한 참여자의 연출 영상만 사용한다.

개인정보 보호법은 공개 장소의 고정형 영상정보처리기기 설치·운영을 제한하고 안내와 안전조치를 요구하며, 이동형 촬영도 법적 근거·촬영 표시 등 조건을 둔다. 시행령은 운영 방침에 목적, 위치·범위, 접근 권한, 촬영·보관·파기 및 보호조치를 포함하도록 한다. 이는 법률 자문을 대신하지 않으며 실제 시험 전 담당자 검토가 필요하다.

### 사람이 판단한 정답 라벨

한 프레임의 “혼잡/비혼잡”이 아니라 5~10초 시간창과 간선 ROI 단위로 두 명이 독립 라벨링한다.

- `visible`: 판독 가능/불가
- `occupancy_band`: 0, 1~3, 4~7, 8명 이상(시험 장면에 맞춰 사전 고정)
- `flow_direction`: 정방향/역방향/양방향/정지/판단 불가
- `crossing_count`: 기준선을 완전히 통과한 사람 수
- `stopped_ratio_band`: 정지 인원 비율 구간
- `occlusion`: 낮음/중간/높음
- `reviewer_agreement`: 일치/불일치 및 조정 기록

“정체” 상태는 사전 합의한 관측 규칙으로만 부여한다. 실제 통행 지연 초는 동선 길이와 개인별 통과시간을 함께 측정해 보정하지 않는 한 정답 라벨로 만들지 않는다.

### AI 없는 기준 방식

- 운영자/관찰자 두 명이 같은 ROI 시간창을 보고 위 라벨을 작성
- 현재 프로토타입처럼 담당자가 확인한 간선에만 고정 지연값을 직접 입력
- 자동 분석과 사람 기준의 일치율, 보류율, 위험한 누락을 비교

### 모델 출력과 경로 엔진 연결

권장 출력은 관측 사실과 불확실성이다.

```json
{
  "map_id": "seoul-station-line4-prototype-v1",
  "edge_id": "E11_OUT",
  "observed_at": "ISO-8601 timestamp",
  "window_s": 10,
  "state": "CLEAR | SLOW_FLOW_CANDIDATE | DENSE_CANDIDATE | UNKNOWN",
  "flow_direction": "FORWARD | REVERSE | BOTH | STOPPED | UNKNOWN",
  "confidence": 0.0,
  "quality_flags": ["OCCLUSION"],
  "source_id": "camera-or-test-clip-id",
  "requires_human_review": true
}
```

현재 엔진의 `congestion_delays: {edge_id: seconds}`에 AI가 초를 직접 써서는 안 된다. 현장 통과시간 정답으로 상태별 지연을 보정하고, 운영 정책과 사람 확인을 거친 후에만 별도 어댑터가 고정 지연 입력으로 변환할 수 있다. 폐쇄 여부도 영상 상태만으로 확정하지 않는다.

### 불확실성과 오판 위험

- 가림·원근 왜곡·역광으로 인원과 속도를 과소 추정
- 반대편 또는 인접 통로 사람을 ROI에 잘못 포함
- 잠깐 멈춘 사람을 정체로 오인하거나 실제 병목을 누락
- 카메라 시계와 지도 상태 불일치, 오래된 관측 재사용
- 오탐은 불필요한 우회, 미탐은 혼잡 구간 제안으로 이어질 수 있음

`UNKNOWN`, 만료시간, 품질 플래그, 사람 검토를 필수로 두고 낮은 신뢰도 결과로 경로를 자동 변경하지 않는다.

## 4. 후보 B — 위치·방향 확인

### 필요한 이미지와 정답

후보 노드마다 최소 4개 진행 방향, 거리·높이·조명·가림을 달리한 이미지가 필요하다.

- `C_CENTER`: `E11_IN`, `E12_IN`, `C05`, `C06` 방향
- `P_SOUTH`: `L4P01`, `L4P02`, `L4P03` 방향
- `C_EAST`: `C03`, `C06`, `E10_IN` 방향
- `C_WEST`: `C04`, `C05`, `E13_IN`, `E14_IN`, `C02` 방향

각 촬영은 `map_id`, 실제 확인한 `node_id`, 카메라가 향한 `outgoing_edge_id`, 방향 등급, 촬영자 위치 오차 범위, 시간, 기기, 조명, 가림, 표지 노출 여부를 기록한다. 그래프 좌표만 보고 실제 장소 라벨을 만들지 않는다. 시설 운영자 또는 현장 기록자가 위치와 방향을 확인해야 한다.

### 유사 장소 오인식 시험

- 같은 후보 노드의 반대 방향
- 계단 A/B처럼 구조가 유사한 장면
- `C_CENTER/C_EAST/C_WEST`의 비슷한 복도·표지 일부만 보이는 crop
- 흔들림, 어두움, 사람 가림, 표지판 제거/가림
- 네 후보 밖의 장면을 `OUT_OF_SCOPE`로 판단하는지 확인
- 학습과 시험에서 같은 연속 촬영 프레임이 섞이지 않도록 촬영 세션 단위 분리

정답 지표는 top-1/top-2 노드·방향 일치율, `OUT_OF_SCOPE` 탐지율, 판단 보류율, 오답을 자신 있게 낸 비율이다. 작은 시험표본의 결과를 전체 역사 성능으로 일반화하지 않는다.

### AI 없는 기준 방식

- QR/NFC/고정 마커로 노드 ID를 읽고 사용자에게 방향 확인
- 표지판 문구 또는 랜드마크 질문을 단계적으로 제시
- 현재 UI의 S1/S2/S3 수동 선택

AI가 이 기준보다 오류·보류·사용시간에서 실질적 이점을 보이지 않으면 AI를 채택하지 않는다.

### 모델 출력과 판단 보류

```json
{
  "map_id": "seoul-station-line4-prototype-v1",
  "node_candidates": [
    {"node_id": "C_CENTER", "confidence": 0.74},
    {"node_id": "C_EAST", "confidence": 0.18}
  ],
  "heading_edge_candidates": [
    {"edge_id": "E12_IN", "confidence": 0.61}
  ],
  "decision": "ASK_CONFIRMATION",
  "quality_flags": ["PARTIAL_SIGNAGE"],
  "model_version": "offline-test-only"
}
```

- 낮은 신뢰도, top-1/top-2 차이가 작음, 범위 밖 장면, 품질 불량이면 `ABSTAIN`.
- 중간 신뢰도면 “12번 표지가 보이나요?”처럼 노드별 확인 질문을 제시.
- 높은 신뢰도라도 사용자가 후보 노드와 방향을 확인한 후에만 다음 단계로 전달.

현재 백엔드는 출발점을 `START` 타입인 S1/S2/S3로 제한한다. `C_CENTER` 같은 `JUNCTION`을 그대로 경로 요청에 넣으면 유효하지 않다. 따라서 이번 시험은 노드·방향 후보 출력까지만 검증하며, 향후 연결에는 검증된 현장 매핑과 API 계약 변경 또는 승인된 시작점 어댑터가 필요하다. 이번 작업에서는 이를 구현하지 않는다.

### 오판 위험

- 반복되는 타일·기둥·계단·표지로 다른 노드를 같은 장소로 오인
- 사용자가 뒤돌아 촬영해 방향을 180도 반대로 판단
- 리모델링·임시 가림·연기·저조도로 데이터 분포 변화
- 잘못된 고신뢰 위치가 잘못된 출발점·방향 안내로 연결

따라서 위치 AI는 단독 안전 장치가 아니라 사용자 확인, 고정 마커, 공식 안내와 결합하는 보조 수단으로 제한한다.
