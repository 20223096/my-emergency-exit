# 내비상구 예선 제출 기술 요약

작성일: 2026-10-28  
프로토타입 상태: 경로 계산·조건 비교·안내 후보 분석 완료 / AI 기술 시험은 설계만 완료

## 제안 문제

현재 서울역 일부 단순화 그래프는 S1~S3와 차단 조건을 알면 경로를 비교할 수 있다. 그러나 실제 이용자는 자신이 어느 안내 후보에 있고 어느 방향을 향하는지, 특정 구간의 관측 상태가 어떤지 알기 어렵다. 이 정보 부족을 줄이는 보조 기술로 두 AI 후보를 검토한다.

- 후보 A: 영상에서 구간별 흐름 상태와 관측 품질을 제시
- 후보 B: 사용자 사진에서 후보 노드·바라보는 간선의 top-k와 판단 보류를 제시

## 기존 프로토타입 근거

| 안내 후보 | 현재 그래프에서의 역할 | 필요한 정보 |
|---|---|---|
| `C_CENTER` | S3 화재 A에서 11→12번으로 갈리는 최초 분기 | 사용자가 중앙 분기점에 있는지, 어느 출구 가지를 보는지 |
| `P_SOUTH` | S3 화재 B에서 계단 A→B로 갈리는 최초 분기 | 사용자가 승강장 분기점에 있는지, 어느 계단 가지가 보이는지 |
| `C_EAST` | S1의 10번 후보와 중앙 방향 선택 | 동측 후보 위치·방향 확인 |
| `C_WEST` | S2의 13/14번 및 중앙 방향 선택 | 서측 후보 위치·방향 확인 |

이 노드들은 공식 시설 위치가 아니라 프로토타입 그래프의 안내 후보이다. 실제 설치·위치 라벨·출구 연결은 현장 검증 대상이다.

## AI 후보 판단

11월 3일 전 우선 시험 후보는 **B. 위치·방향 확인**이다. 이유는 통제 촬영으로 노드·방향 정답을 만들고 유사 장소 오답과 판단 보류를 측정할 가능성이 후보 A보다 높기 때문이다. 목표는 정확한 실내 측위나 AR이 아니라 네 후보 중 top-k와 방향 후보를 제시하는 제한된 오프라인 시험이다.

후보 A는 후속 시험 후보로 유지한다. 예선 전에는 권한이 있는 연출 영상에서 `CLEAR/SLOW_FLOW_CANDIDATE/DENSE_CANDIDATE/UNKNOWN`과 품질 플래그를 출력하는 파이프라인까지만 설계한다. 영상만으로 초 단위 지연을 생성하지 않으며, 실제 경로 엔진의 고정 지연 입력으로 자동 변환하지 않는다.

## 비-AI 기준

- 위치·방향: QR/NFC/고정 마커, 표지·랜드마크 확인 질문, S1/S2/S3 수동 선택
- 구간 상태: 운영자 두 명의 독립 관찰과 현재 UI의 검증된 고정 지연 수동 입력

AI가 이 기준보다 오류, 판단 시간, 운영 부담에서 이점을 보이지 않으면 채택하지 않는다.

## 안전한 연결 원칙

1. 후보 A 출력은 `edge_id`, 상태, 신뢰도, 품질, 시각으로 제한한다.
2. 후보 B 출력은 `node_candidates`, `heading_edge_candidates`, `ABSTAIN/ASK_CONFIRMATION`으로 제한한다.
3. 낮은 신뢰도와 범위 밖 입력은 공식 안내 확인으로 전환한다.
4. AI가 차단·지연·출발점을 자동 확정하지 않는다.
5. 현재 API는 S1/S2/S3 같은 START 노드만 출발점으로 허용한다. `C_CENTER/P_SOUTH/C_EAST/C_WEST` 출력은 현재 엔진에 직접 입력할 수 없다.

## 현재 확인된 것

- 기존 그래프에서 S3 화재 A의 최초 분기는 `C_CENTER`, 화재 B는 `P_SOUTH`다.
- S3 계단 A+B 차단은 도달 불가로 처리된다.
- AI 후보가 제공해야 할 출력 계약, 정답 라벨, 비-AI 기준, 보류 정책을 정의했다.
- 개인정보·영상 권한 게이트와 11월 3일까지의 시험 절차를 정의했다.

## 확인되지 않은 것

- 실제 역사 영상·사진 사용 권한과 현장 촬영 허가
- 실제 장소와 그래프 후보 노드의 좌표 대응
- 계단 B의 실제 존재와 방향 이미지
- AI 정확도, 실시간 처리, 현장 일반화, 사용자 안전 효과
- 영상 상태와 실제 통과 지연 초의 관계
- AI 출력의 실제 경로 엔진 연동

따라서 예선에서는 “AI 구현 완료”가 아니라 **실제 데이터와 안전 게이트를 전제로 한 비교·시험 계획 수립**으로 제출한다. 자료가 확보되지 않으면 성공 결과를 기재하지 않는다.
