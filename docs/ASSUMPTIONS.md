# 실험 가정과 한계

## 현재 가정값

- 샘플 지도는 실제 서울역이 아닌 가상 복합시설입니다.
- 통로 길이 단위는 m, 속도는 m/s, 지연과 결과 시간은 초입니다.
- 기본 보행속도는 API 기본값 `1.2 m/s`이며 `(0, 10]` 범위만 허용합니다.
- 반응시간은 `[0, 3600]초`이며 출발 전 정확히 한 번만 최종 시간에 더합니다.
- 모든 통로는 동일한 요청 보행속도를 사용합니다. 계단도 별도 속도 보정 없이 길이/속도로 계산합니다.
- 혼잡은 지정 간선 통과 시 고정 추가 지연(0 이상)으로 모델링합니다.
- 최적화 비용은 `length_m / walking_speed_mps + congestion_delay_s`의 합입니다.
- 동률이면 선택 출구 ID, 노드 ID 경로, 간선 ID 경로의 사전순으로 결정해 같은 입력에 같은 결과를 냅니다.
- 닫힌 출구는 목적지뿐 아니라 그래프 노드 자체에서 제외됩니다.

## 실제 근거자료가 필요한 항목

실제 통로 길이와 연결성, 통행 방향, 출구 운영 상태, 계단별 이동속도, 이용자군별 보행속도, 반응시간, 혼잡 지연 함수, 재난 유형별 통제 구간은 현장 조사·공인 자료·기획팀 정의가 필요합니다.

## 한계

이 결과는 동일한 가상 공간에서 입력 조건을 바꾼 모의 비교이며 서비스 도입 효과나 안전성을 의미하지 않습니다. 화재·연기 확산, 통로 용량, 군중 상호작용, 시간에 따른 상태 변화, 실시간 위치, 접근성 요구와 실제 대피 적합성을 예측하지 않습니다.

## 후속 범위

실제 지도와 근거값을 받으면 데이터 교체 및 검증, 계단/이용자별 속도 정책, 통로 용량 모델, 시나리오 보강이 필요합니다. UI 초안 확정 뒤에는 지도 좌표 렌더링, 조건 선택, baseline/scenario 비교 표시와 오류·경로 없음 상태를 API 계약에 맞춰 연결해야 합니다.
