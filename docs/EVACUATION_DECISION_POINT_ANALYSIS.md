# 재난 시나리오 경로 변경·안내 후보 지점 분석

검증 기준: `ad4cfaf7dbcf0fa6a14bdee811bc2bc36ddf32f4`  
지도/버전: `seoul-station-line4-prototype-v1`  
기본 입력: 평지 1.2m/s, 계단 0.8m/s, 출발 지연 0초

> 이 문서의 모든 노드·간선·좌표·거리·시간은 서울역 일부를 단순화한 **프로토타입 계산 그래프**의 값이다. 실제 서울역 공식 시설 위치, 실제 보행거리, 공식 비상구, 위험·혼잡 지점을 뜻하지 않는다. `(x, y)`는 SVG 배치용 상대좌표이며 미터 좌표가 아니다.

## 1. 분석 방법과 용어

- `분기점`: 그래프에서 둘 이상의 진행 방향을 선택할 수 있는 노드. 예: `P_SOUTH`, `C_CENTER`.
- `차단 위치`: 시나리오 입력에서 제외된 간선. 예: `STAIR_A`, `E11_OUT`.
- `최초 분기점`: 기본 경로와 조건 경로가 마지막으로 같은 노드를 지난 뒤 서로 다른 간선을 선택하는 노드.
- 결과는 현재 Dijkstra 기반 계산이 모의 이동시간을 최소화해 고른 경로다. 실제 현장의 선택 행동이나 안전성을 예측하지 않는다.
- 출구 ID는 일반 지하철 출입구 후보이며 `official_evacuation_exit`는 미확인 상태다.

## 2. 그래프 구조와 기본 경로

| 출발점 | 기본 노드 순서 | 기본 간선 | 포함 분기점 | 포함 계단 | 결과 |
|---|---|---|---|---|---|
| S1 | `S1 → C_EAST → X10_APPROACH → EXIT_10` | `C03, E10_IN, E10_OUT` | `C_EAST` | 없음 | 10번, 30m, 25.0초 |
| S2 | `S2 → C_WEST → X13_APPROACH → EXIT_13` | `C04, E13_IN, E13_OUT` | `C_WEST` | 없음 | 13번, 37m, 30.833초 |
| S3 | `S3 → P_SOUTH → STAIR_A_LOWER → STAIR_A_UPPER → C_CENTER → X11_APPROACH → EXIT_11` | `L4P01, L4P02, STAIR_A, C01, E11_IN, E11_OUT` | `P_SOUTH, C_CENTER` | `STAIR_A` | 11번, 56m, 52.5초 |

`STAIR_A_LOWER/UPPER`와 `STAIR_B_LOWER/UPPER`는 계단 단부 노드이지 분기점이 아니다. `X11_APPROACH`도 현재 토폴로지에서는 두 간선만 잇는 접근 노드이므로 대체 방향 선택 지점으로 분류하지 않는다.

## 3. 시나리오별 경로 변경

### 화재 A: `E11_OUT` 차단

차단 간선은 `X11_APPROACH ↔ EXIT_11`이다. 출구 자체 폐쇄 입력과는 다르지만, 이 그래프에서는 11번 후보에 들어가는 유일한 마지막 간선이므로 S3의 11번 경로를 사용할 수 없게 한다.

- S1: 기본 경로에 `E11_OUT`이 없어 10번·30m·25.0초 유지.
- S2: 기본 경로에 `E11_OUT`이 없어 13번·37m·30.833초 유지.
- S3: `C_CENTER`까지 기본 경로와 동일하고 여기서 `E11_IN` 대신 `E12_IN`을 선택한다.
- S3 조건 경로: `L4P01 → L4P02 → STAIR_A → C01 → E12_IN → E12_OUT`.
- 결과: 12번, 60m, 55.833초. 기본 대비 +4m, +3.333초.
- **최초 분기점 `C_CENTER`와 차단 위치 `E11_OUT`은 같은 지점이 아니다.**

### 화재 B: `STAIR_A` 차단

차단 간선은 `STAIR_A_LOWER ↔ STAIR_A_UPPER`이다.

- S1/S2: 두 기본 경로 모두 계단 A를 사용하지 않아 결과 유지.
- S3: `S3 → P_SOUTH`까지 동일하고 `P_SOUTH`에서 `L4P02` 대신 `L4P03`을 선택한다.
- S3 조건 경로: `L4P01 → L4P03 → STAIR_B → C02 → E13_IN → E13_OUT`.
- 결과: 13번, 66m, 61.667초. 기본 대비 +10m, +9.167초.
- **최초 분기점은 `P_SOUTH`이고 차단 위치는 그 뒤의 `STAIR_A`이다.**
- `STAIR_B`의 실제 존재·위치·사용 가능성은 확인되지 않은 프로토타입 가정이다.

### 계단 A+B 차단

S3에서 승강장층(-2)과 대합실층(-1)을 잇는 두 가정 간선 `STAIR_A`, `STAIR_B`가 모두 제외된다. 결과는 도달 불가이며 출구·거리·시간은 모두 `null`, 경로는 빈 배열이다. S1/S2는 이미 -1층에 있고 해당 계단을 사용하지 않으므로 영향이 없다.

## 4. 출구가 달라지는 조건

현재 검증된 S3 입력에서 다음 조건이 출구를 바꾼다.

| 조건 | 기본 출구 → 조건 출구 | 구조상 이유 |
|---|---|---|
| `E11_OUT` 차단 | 11 → 12 | `C_CENTER`에서 11번 마지막 접근 대신 12번 가지 선택 |
| `EXIT_11` 폐쇄 | 11 → 12 | 11번 후보와 연결 간선을 후보 그래프에서 제외 |
| `STAIR_A` 차단 | 11 → 13 | `P_SOUTH`에서 계단 B 가지로 전환하면 `C_WEST`에 도착 |
| `STAIR_A + STAIR_B` 차단 | 11 → 없음 | S3에서 -1층으로 올라가는 두 모델 경로가 모두 끊김 |

S1/S2에 변화가 없는 이유는 화재 A/B 차단 간선이 각 기본 경로에 없고, 각각 `C_EAST → EXIT_10`, `C_WEST → EXIT_13`의 더 짧은 유효 경로가 그대로 남기 때문이다. 이는 현재 계산 그래프에 한정된 사실이며 실제 공간에서 영향이 없다는 뜻이 아니다.

## 5. 모든 연결 경로가 사라지는 최소 차단 조합

간선 1개와 2개 조합을 전수 계산해, 그보다 작은 단절 조합을 포함하지 않는 최소 조합을 정리했다. 각 조합의 상위집합도 당연히 도달 불가가 된다.

| 출발점 | 최소 단절 조합 |
|---|---|
| S1 | `{C03}`; `{C06, E10_IN}`; `{C06, E10_OUT}` |
| S2 | `{C04}` |
| S3 | `{L4P01}`; A가지의 `{L4P02, STAIR_A, C01}` 중 하나와 B가지의 `{L4P03, STAIR_B, C02}` 중 하나를 짝지은 9개 조합 |

S3의 9개 쌍은 `{L4P02,L4P03}`, `{L4P02,STAIR_B}`, `{L4P02,C02}`, `{STAIR_A,L4P03}`, `{STAIR_A,STAIR_B}`, `{STAIR_A,C02}`, `{C01,L4P03}`, `{C01,STAIR_B}`, `{C01,C02}`이다. 현재 등록 시나리오는 이 중 `{STAIR_A, STAIR_B}`만 사용한다. 이 단절 분석은 그래프 연결성 시험이지 실제 폐쇄 가능성이나 현장 위험 평가가 아니다.

## 7. 모델이 확인한 사실과 추가 검증

### 모델이 확인한 사실

- 주어진 간선 차단 입력에 따라 위 경로·출구·가정 거리·모의 시간이 재현된다.
- 화재 A의 최초 경로 분기는 `C_CENTER`, 화재 B의 최초 경로 분기는 `P_SOUTH`다.
- S3의 두 계단 간선을 모두 제외하면 현재 그래프에 출구까지 연결된 경로가 없다.
- S1/S2 기본 경로는 화재 A/B 간선을 사용하지 않는다.

### 추가 현장 검증이 필요한 사항

- 모든 내부 노드·간선의 실제 존재, 방향, 길이, 층간 연결과 통행 가능성
- 계단 B의 존재 및 비상시 사용 가능 여부
- 출구 후보의 공식 피난 출구 지정 여부와 재난별 운영 상태
- 표지 가시거리, 설치 가능 위치, 접근성, 역류·집결 영향
- 공식 재난 방송·역무원 통제와 문구의 우선순위 및 연계 방식
