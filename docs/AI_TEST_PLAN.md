# AI 후보 오프라인 기술 시험 계획

시험 계획일: 2026-10-28  
예선 목표일: 2026-11-03  
상태: **설계만 완료 — 실제 데이터·모델·성공 결과 없음**

## 1. 공통 원칙과 완료 조건

1. 실제 영상/사진은 권한, 목적, 고지, 보관·파기, 접근자를 확인하기 전 수집하지 않는다.
2. 모델 개발용과 최종 시험용 데이터를 촬영 세션 단위로 분리한다.
3. 정답은 그래프 좌표로 추정하지 않고 현장 확인자 또는 통제된 촬영 계획으로 기록한다.
4. 정확도뿐 아니라 판단 보류, 고신뢰 오답, 범위 밖 입력을 보고한다.
5. 시험 결과는 실제 재난 안전성·군중 지연·실내 측위·AR 구현으로 표현하지 않는다.

예선 전 최소 완료 산출물은 데이터 사용 승인 기록, 데이터시트, 라벨 지침, 블라인드 평가표, 실패 사례, 채택/보류 판단이다. 자료가 없으면 “미실행”으로 제출한다.

## 2. 사전 게이트

| 게이트 | 통과 증거 | 미통과 시 조치 |
|---|---|---|
| 사용 권한 | 소유자/운영자 승인, 허용 목적·범위·기간 | 실제 자료 사용 중단 |
| 개인정보 | 법적 근거 검토, 고지/동의, 최소수집, 접근·보관·파기 계획 | 합성/빈 공간/동의한 연출 자료로 대체 |
| 현장 정답 | 노드·방향 또는 ROI-간선 매핑을 담당자 2인이 확인 | 모델 평가 금지 |
| 데이터 분리 | 촬영 세션 기준 train/test 명단 | 재분할 후 재시험 |
| 중단 정책 | `UNKNOWN/ABSTAIN`, 만료, 사람 확인 규칙 | 경로 엔진 연결 금지 |

## 3. 시험 A — 구간 상태 분류

### 목적

영상 시간창에서 간선 ROI의 관측 상태와 품질을 사람 라벨과 비교할 수 있는지 확인한다. 초 단위 지연은 추정하지 않는다.

### 실제 입력 예시 계획

실제 자료는 아직 없다. 권한이 확보되면 다음 2개 통제 장면을 촬영한다.

1. `E11_OUT` 대체 테스트 ROI: 동의한 참여자 2~3명이 한 방향으로 통과하는 10초 영상.
2. `L4P02` 또는 계단 A 대체 테스트 ROI: 참여자 일부가 멈추고 일부가 반대 방향으로 움직이며 가림이 발생하는 10초 영상.

실제 서울역 촬영이 허용되지 않으면 일반 실내 통로의 연출 영상을 쓰되 그래프 간선의 실제 상태라고 부르지 않는다.

### 절차

1. 카메라와 ROI를 고정하고 원본 ID·시간·조건을 기록한다.
2. 두 라벨러가 독립적으로 `visible`, 인원 구간, 방향, 통과 수, 정지 비율, 가림을 기록한다.
3. 불일치를 보존한 뒤 조정 라벨을 별도 작성한다.
4. 단순 기준선(수동 관찰 또는 기본 검출·추적)과 후보 모델을 같은 시간창에 실행한다.
5. 상태 일치율, 통과 수 오차, `UNKNOWN` 적절성, 위험한 미탐을 보고한다.
6. 출력 JSON 스키마를 검증하되 경로 API에는 전송하지 않는다.

### 평가표

| 지표 | 의미 | 예선 판단 기준 |
|---|---|---|
| 라벨러 일치율 | 정답 자체의 안정성 | 낮으면 상태 정의부터 수정 |
| 상태 macro-F1 | 불균형 상태별 분류 | 수치 보고만; 소표본 성공 주장 금지 |
| crossing count MAE | 통과 수 오차 | 사람 기준과 함께 보고 |
| unknown recall | 판독 불가 장면을 보류 | 가림 장면에서 필수 확인 |
| confident miss | 정체 후보를 고신뢰 CLEAR로 출력 | 1건이라도 별도 위험 분석 |

### 통과의 의미

출력 스키마와 보류 정책을 시험할 수 있다는 의미일 뿐이다. `congestion_delays`의 초 값을 생성할 근거는 되지 않는다. 지연 연결 시험은 현장 통과시간 자료와 정책 승인이 확보된 후 별도 단계로 둔다.

## 4. 시험 B — 후보 노드·방향 분류

### 목적

사진 한 장에서 네 안내 후보 중 top-k 노드와 진행 간선 후보를 제시하고, 모호할 때 보류 또는 확인 질문을 내는지 평가한다. 정확한 연속 좌표나 AR 자세를 구하지 않는다.

### 실제 입력 예시 계획

실제 자료는 아직 없다. 권한이 확보되면 다음 장면부터 시작한다.

1. `C_CENTER`에서 `E11_IN` 방향과 `E12_IN` 방향을 각각 촬영한 이미지. 같은 위치의 반대 방향 오인을 측정한다.
2. `P_SOUTH`에서 `L4P02`(계단 A 가지)와 `L4P03`(계단 B 가정 가지) 방향 이미지. 실제 계단 B 존재가 검증되지 않으면 해당 라벨은 만들지 않는다.

`C_EAST/C_WEST`는 유사 복도 음성·표지 확인 질문의 비교군으로 추가한다.

### 최소 데이터 구성안

- 후보 4곳 × 유효 방향 3개 이상 × 독립 촬영 세션 3회 × 조건 3종(밝음/어두움/가림)
- 후보 밖 장소 `OUT_OF_SCOPE` 세션 포함
- 촬영 세션 하나 전체를 최종 시험으로 보류
- 실제 수량은 승인과 현장 구조 확인 뒤 확정하며, 부족하면 탐색 시험으로만 표기

### 절차

1. 현장 확인자가 노드·바라보는 간선·촬영 허용 범위를 기록한다.
2. QR/NFC 또는 표지 질문 방식의 비-AI 기준을 같은 사용자 과업으로 측정한다.
3. 이미지 분류/검색 방식으로 top-2 후보와 신뢰도를 출력한다.
4. 임계값은 개발 세트에서만 정하고 블라인드 세트에 고정 적용한다.
5. 저품질, 유사 장소, 반대 방향, 범위 밖 장면에서 `ABSTAIN`을 평가한다.
6. 중간 신뢰도 입력은 랜드마크 확인 질문으로 전환하고 사용자 응답 후 정답 여부를 기록한다.

### 평가표

| 지표 | 의미 | 중단 조건 |
|---|---|---|
| node/edge top-1·top-2 | 후보 분류 성능 | 수치만으로 자동 안내 허용 금지 |
| high-confidence error | 자신 있는 오답 | 발생 시 임계값·사용 흐름 재설계 |
| abstain precision/recall | 모호한 장면 보류 품질 | 범위 밖을 고신뢰 분류하면 중단 |
| confirmation recovery | 확인 질문 후 정답 회복 | 질문이 오히려 오답을 강화하면 중단 |
| task time/error vs QR | 비-AI 기준 대비 효용 | QR보다 나쁘면 AI 채택 보류 |

### 엔진 연결 모의 시험

출력은 `{node_candidates, heading_edge_candidates, decision}`까지만 저장한다. 현재 경로 API가 JUNCTION 시작을 거부하므로 실제 `/api/routes` 요청을 만들지 않는다. 향후에는 다음 중 하나를 별도 설계 검토한다.

- 현장 검증된 후보 노드를 승인된 S1/S2/S3 시작영역으로 매핑
- 라우팅 계약이 임의 유효 노드 시작을 지원하도록 변경
- AI를 경로 계산이 아닌 “현재 표지 방향 확인”에만 사용
