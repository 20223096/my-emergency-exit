# 프로토타입 데이터 출처와 한계

## 확인된 것

- 프로젝트 기획 범위가 S1 대합실, S2 1호선→4호선 환승 연결 구간, S3 4호선 승강장 계단 주변을 대상으로 지정했다.
- 기획 범위와 공개 역사 안내 참고값에서 서울역 10~14번 출입구 번호를 식별했다.
- 애플리케이션 코드와 테스트로 그래프 무결성, 결정적 경로 계산, 차단·혼잡·unreachable 처리를 확인했다.

출구 번호 노드의 `MAP_CONFIRMED`는 번호가 일반 출입구 후보로 식별됐다는 뜻이다. 내부 접근 경로 또는 공식 피난 출구가 확인됐다는 뜻이 아니다.

## 단순화한 것

- S1/S2/S3 위치를 상대 좌표의 대표 노드로 축약했다.
- 대합실, 환승 구간, 승강장 영역을 발표용 SVG 배경 영역으로 단순화했다.
- 실제 공간의 폭, 기둥, 개찰구, 문, 장애물과 세부 계단 형상은 표현하지 않았다.

## 시뮬레이션을 위해 가정한 것

- 모든 내부 갈림길과 출구 접근 간선의 정확한 연결
- 계단 A와 대체 계단 B의 위치·길이·연결
- 모든 `length_m` 값
- 계단 0.8m/s, 평지 1.2m/s와 반응시간 5초
- 혼잡 구간의 고정 초 단위 추가 지연
- 화재 A/B의 발생 위치와 차단 범위

모든 간선 길이는 `실험용 가정값`이며 SVG 좌표에서 미터로 환산하지 않았다. 계단 B는 실제 대체 계단의 존재를 확인한 결과가 아니다.

## 구현하지 않은 것

- 공식 소방 피난계획 또는 법정 피난 출구 검증
- 연기·열·가시거리·유독가스 확산
- 시간에 따라 변하는 화재와 통로 위험도
- 군중 밀도·상호작용·병목의 물리 모델
- 개인의 인지·되돌아감·의사결정 변화
- 장애인·노약자별 접근성 및 엘리베이터 운용 정책
- 현장 측량과 실제 소요시간 검증

따라서 결과의 거리·시간은 두 가정 그래프 조건을 비교하는 모의 값이다. 사람의 행동 개선 효과, 실제 생존 가능성 또는 안전성을 입증하지 않는다.

## 제출 후 필요한 검증

1. 기획팀 원본 이미지/PDF의 저장소 편입 또는 버전이 고정된 출처 기록
2. 서울교통공사 또는 관계 기관 자료로 층·통로·계단·출구 연결 검증
3. 현장 조사로 통행 방향, 폐쇄 단위와 실제 거리 확인
4. 공식 피난 출구와 일반 출입구의 별도 데이터 모델 확정
5. 검증 결과에 따라 `active_for_routing`, provenance와 가정 거리를 갱신
