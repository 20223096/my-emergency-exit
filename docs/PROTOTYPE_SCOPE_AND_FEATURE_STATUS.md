# 프로토타입 범위 및 기능 현황

## 모델 목적

서울역 일부 구역의 단순화 그래프에서 출발 위치, 이동속도, 출발 지연, 통로 차단, 출구 폐쇄, 사용자가 지정한 고정 지연에 따라 경로·출구·거리·모의 시간이 어떻게 달라지는지 비교한다.

## 기능 감사

| 기능 | 상태 | 근거/비고 |
|---|---|---|
| S1/S2/S3 선택 | 현재 구현됨 | 지도 START 노드와 API `start_node_id` |
| 평지·계단 속도 | 현재 구현됨 | CORRIDOR/STAIR별 시간 가중치 |
| 출발 지연 | 현재 구현됨 | 이동시간에 `reaction_delay_s`를 더함 |
| 화재 A/B | 현재 구현됨 | 사전 정의한 가정 차단 시나리오. 화재 확산 모델 아님 |
| 통로 차단 | 현재 구현됨 | 차단 간선을 adjacency에서 제외 |
| 출구 폐쇄 | 현재 구현됨 | 후보 및 경유에서 폐쇄 출구 제외 |
| 고정 혼잡 지연 | 현재 구현됨 | 지정 간선에 사용자 입력 초를 더함. 군중 예측 아님 |
| 재난 전 참고 경로/조건 경로 | 현재 구현됨 | compare API가 동일 속도·출발 지연의 무차단 기준과 조건 결과 반환 |
| 출구·거리·모의 시간 | 현재 구현됨 | API 결과를 UI에 표시 |
| 우회거리·추가시간 | 현재 구현됨 | 양쪽 모두 도달 가능할 때만 delta 표시 |
| 도달 불가 | 현재 구현됨 | 거리/시간/delta를 `—` 또는 숨김 처리 |
| 지도·경로 일치 | 현재 구현됨 | API `path_edges` ID를 동일 JSON 그래프 SVG 간선에 직접 매핑 |
| 입력 전/가능/계산 중/완료 | 이번 작업에서 보완 | 필수 재난 선택, disabled, 로딩 및 중복 클릭 방지 |
| 조건 변경 stale 방지 | 이번 작업에서 보완 | 결과와 overlay 즉시 제거, 재계산 안내 |
| 입력 오류 | 이번 작업에서 보완 | 속도·지연 범위의 항목별 문구 |
| API 오류/재시도 | 이번 작업에서 보완 | 결과와 별도 오류 alert 및 마지막 동작 재시도 |
| 경로 표시 토글 | 이번 작업에서 보완 | 계산 전 비활성, 계산 후 각 overlay 독립 표시 |
| 누적거리/계단 층 이동 | 이번 작업에서 보완 | 경로 구간 목록에서 실제 간선 누적 합과 층 표시 |

## 데이터 및 해석 경계

- 현재 그래프의 좌표·거리 중 다수는 `SIMPLIFIED` 또는 `SIMULATION_ASSUMPTION`이며 실제 측량값이 아니다.
- 공식 안내도는 공간 이해 참고자료이고, 현재 경로는 단순화 그래프 계산 결과다. 좌표 정합은 검증되지 않았다.
- `official_evacuation_exit`가 검증되지 않은 일반 출구를 비상구로 부르지 않는다.
- 기본 경로는 “동일 입력의 고정 경로”가 아니라 동일 출발점·속도·출발 지연에서 차단/폐쇄/추가 지연을 제거한 **재난 전 참고 경로**다.

## 구현 상태 구분

- 현재 구현됨: 결정적 경로 계산, 그래프 표시, 시나리오/속도/지연/차단/폐쇄, API.
- 이번 작업에서 새로 구현함: 완전한 UI 상태, 필수 입력, stale 제거, 재시도, 토글, Figma 수치 기반 layout, 모바일 QA.
- 설계만 존재: 실제 안내도와 계산 좌표의 정합, 시간 재생, 다중 이용자 이동.
- 실제 데이터 미확보: 실측 이동거리, 실제 통행 가능성, 실시간 인구 밀도, 공식 비상구 판정.
- 향후 AI/AR 개발 대상: 인파 흐름 분석 AI, 위치·방향 확인 AI, AR 안내. 현재 구현됐다고 주장하지 않는다.
