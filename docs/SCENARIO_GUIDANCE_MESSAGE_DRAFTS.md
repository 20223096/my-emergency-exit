# 시나리오 설명 및 안내 문구 시안

> 아래 시민용 문구는 **프로토타입 사용성 시험용 문구**다. 실제 재난 시 공식 지침·역무원 안내·재난 방송을 대체하지 않으며, 실제 서울역의 안전한 경로를 보증하지 않는다. 출구 번호는 현재 모델의 일반 출입구 후보이다.

공통 계산 조건은 지도 `seoul-station-line4-prototype-v1`, 평지 1.2m/s, 계단 0.8m/s, 출발 지연 0초다.

## S1

- 기본: `S1-C_EAST-X10_APPROACH-EXIT_10`, 간선 `C03-E10_IN-E10_OUT`.
- 결과: 10번, 30m, 25.0초.
- 화재 A 차단 `E11_OUT` 및 화재 B 차단 `STAIR_A`는 이 경로에 포함되지 않는다. 두 조건에서도 경로·출구·거리·시간 변화가 없다.
- 관련 선택 노드는 `C_EAST`; 계단은 사용하지 않는다.

### 시민용 시안

> **사용성 시험용 안내** — 현재 모델에서는 S1에서 10번 출구 후보 방향 경로가 유지됩니다. 입력된 11번 접근 통로 또는 계단 A 차단은 이 모의 경로에 포함되지 않습니다. 실제 이동 전 공식 안내와 현장 통제를 확인해 주세요.

## 문구 사용성 시험에서 확인할 항목

- “현재 모델”, “출구 후보”, “사용성 시험용” 표현이 실제 공식 지침과 혼동되지 않는가
- 차단 위치와 방향 전환 위치를 사용자가 구분하는가
- 출구 번호뿐 아니라 다음 결정 지점까지의 방향 정보가 필요한가
- 경로 없음 문구가 불필요한 이동을 유도하지 않고 공식 안내 확인을 촉진하는가
- 시각·청각·인지 접근성을 고려한 표현과 다국어 제공이 필요한가
